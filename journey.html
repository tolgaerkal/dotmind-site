Example journey: applying for a service

One interaction in detail: who does what at each step, from a resident’s first question to the decision. Agents check and prepare; people decide.

1 · Ask
2 · Submit
3 · Check
4 · Review
5 · Update
Resident
Asks what’s needed for the service
Uploads application and files
Receives plain-language update, reasons and how to appeal
Agents
Guide agent answers from official guidance; builds a personal checklist
Intake agent checks each file at upload: complete, legible, in date, right type; explains fixes
Review assistant reads documents, verifies identity, matches details to the rules, prepares a summary with evidence
Drafts the decision or information request for the caseworker to edit
Update agent sends approved messages and answers status questions
Staff
Caseworker reviews summary and flags, then approves, denies or requests more
Handles anything the agent hands off
State systems
Files stored in the state’s case system
Identity, eligibility rules and records checked through secure connectors
Decision recorded in the case system

Safeguards at every step

Human decision at step 4, alwaysEvery agent action loggedAccess limited to each taskAgents tested on real cases before launchA person reachable at every step
